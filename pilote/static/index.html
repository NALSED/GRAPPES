GRAPPES

Réglages

Configurer les sources, la vérification et la sortie. La page montre le dernier état connu de chaque source avec sa date : elle n'appelle rien toute seule. Aucune fiabilité ici — ça, c'est la page Tri. Chaque bloc s'ouvre et se ferme ; replié, il garde son état et un rappel de ce qui est réglé.

Assistant de configuration

Rouvre l'assistant à l'étape voulue, sans refaire toute l'installation. Seule l'étape rejouée est modifiée.

Budget

Toutes les unités (crédits, jetons, requêtes) sont converties en dollars. Au plafond, le programme s'arrête proprement.

Presets

Des lots de sources prêtes à l'emploi, calculés à partir de ce que chaque source déclare. Combinables : coche ceux que tu veux par défaut.

Bases officielles de mon pays

Le catalogue de ce qui existe : les bases publiques connues pour un pays, avec leur licence et la date de dernière vérification. Cochées d'après tes presets. Rien n'est téléchargé d'ici sans ton accord.

Copies locales

Ce qui est réellement sur le disque. Une copie téléchargée sert hors ligne et donne les mêmes résultats d'un jour à l'autre. Rien n'est téléchargé sans ton accord, après avoir vu le poids et la place libre. Pas de filtre par mot-clé.

Ajouter une nouvelle source

Choisis le type : un encart s'ouvre dessous avec ce que ce type demande. La clé, si elle est demandée, est rangée par le programme lui-même (jamais à copier dans un fichier, jamais réaffichée). La source est enregistrée éteinte, puis testée sans rien appeler ; elle apparaît dans Réglages. Une source qui demande un adaptateur est enregistrée quand même, et le dit.

Ces cas demandent un petit programme (un adaptateur). La source est enregistrée quand même avec ce que tu donnes ici ; Réglages affichera « cette source demande un adaptateur » et ne l'allumera pas avant.

Tri

  

    
    
  

  
Deux signaux séparés, jamais mélangés en une note : la couleur et le mot disent d'où vient un nom (sa qualité de source) ;
    le nombre dit à combien d'endroits différents il a été trouvé. « 3 endroits » sur le web ne vaut pas « 1 endroit » dans un registre officiel.
