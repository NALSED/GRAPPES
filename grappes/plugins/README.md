# plugins/

Déposez ici un fichier `.py` pour brancher un fournisseur de recherche trop complexe pour le YAML. Il est
découvert automatiquement ; aucun fichier du dépôt n'est modifié. Les `.py` de ce dossier ne sont pas suivis
par git. Guide : `docs/utilisateur.md`, section « Brancher une nouvelle API en 10 minutes ».
