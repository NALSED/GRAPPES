# 3.8.01 — Format JSON/CSV : le séparateur devient réel

Répond au point **3.8**, outil 1.

## Ce qui marche déjà, ce qui ne marche pas

* **« Format de sortie »** (CSV / JSON) est déjà branché : il choisit quel(s) fichier(s) l'export
  produit (`suite_plan.py` → `api_suite.py` → `sortie.py`). Rien à changer ici.
* **« Séparateur »** ne sert à rien aujourd'hui : `sortie.py` écrit toujours `;` (et `,` pour
  l'export « nom seul »), quelle que soit la valeur tapée dans ce champ. Commentaire du code :
  « le séparateur n'est pas réglable ».

## Ce que momo change

* Le champ « Séparateur » devient un choix fermé à deux valeurs : **`;`** (par défaut, inchangé) ou
  **`,`**.
* `sortie.py` (export « tsites » et « detail ») utilise ce choix au lieu du `;` en dur. L'export
  « nom seul » reste à `,` dans tous les cas (une seule colonne, le séparateur n'a pas de sens).
* Le choix part du même chemin que « Format de sortie » : `suite_plan.py` → `comp["format"]` /
  nouveau `comp["separateur"]` → `api_suite.py` → `sortie.py`.

## Comment momo vérifie

* Choisir `,` dans une tuile Format, exporter en CSV « detail » : les colonnes sont séparées par
  des virgules, pas des points-virgules.
* Choisir `;` (par défaut) : comportement actuel inchangé.
* Export « nom seul » : toujours une colonne, le réglage n'a pas d'effet visible (normal).
