# 3.3 — Bouton allumer/éteindre, et boutons en icône seule

Répond au point **3.3** du pavé de Sednal du 02/11/2026.

## 1. Le bouton allumer/éteindre sur la ligne source

Il existe déjà sur la tuile outil (`carteOutil`, `static/suite/js/reglages.js`) — à reproduire à
l'identique sur la ligne source (`ligneSource`, même fichier).

Source d'inspiration, déjà en production pour les outils :

````js
bouton({ libelle: eteint ? VERBES.allumer : VERBES.eteindre, icon: "interrupteur", petit: true,
  onclick: () => basculerOutil(o), "aria-label": `${eteint ? VERBES.allumer : VERBES.eteindre} ${o.nom}` })
````

Pour les sources, la bascule existe déjà **dans le panneau** (`ficheSource`, lignes 179-182) :

````js
const interrupteur = edition && bouton({ libelle: s.etat === "off" ? VERBES.allumer : VERBES.eteindre, icon: "interrupteur", petit: true, onclick: async () => {
  if (s.etat === "off") await allumerSource(s);
  else await agir(() => api.post(`/sources/${id}/eteindre`), { succes: `« ${s.nom} » est éteinte.` });
}});
````

Extraire cette logique dans une fonction `basculerSource(s)` (symétrique à `basculerOutil`), et
l'appeler depuis **les deux endroits** : le panneau et la ligne. Elle réutilise `allumerSource(s)`
pour le sens risqué (qui gère déjà l'avertissement 409), et l'appel direct `.../eteindre` pour
l'extinction — personne n'a jamais besoin d'un avertissement pour éteindre une source.

Résultat : **trois** actions sur la ligne source, dans cet ordre (Modifier et Retirer ne bougent
pas de place, l'interrupteur s'ajoute entre les deux) :

````
[Modifier] [Allumer/Éteindre] [Retirer]
````

## 2. Icône seule, partout où une liste porte des actions

Aujourd'hui `bouton({ petit: true, icon, libelle })` affiche le pictogramme **et** le mot. Il existe
déjà un composant dédié à l'icône seule, `boutonIcone({ icon, etiquette, onclick })`
(`static/suite/js/ui.js`), réservé jusqu'ici au `×`, au chevron, aux ports et à l'envoi de l'Aide.

**Sa réserve d'usage s'élargit** : tout bouton d'action dans une ligne ou une tuile de liste
(sources, outils) passe par `boutonIcone`, avec son nom en `etiquette` — jamais un bouton d'action de
liste en `bouton({ petit: true })` désormais.

Endroits à changer dans `static/suite/js/reglages.js` :

| Fonction | Boutons à convertir |
| :-- | :-- |
| `ligneSource` | Modifier, (nouveau) Allumer/Éteindre, Retirer |
| `retireesVue` | Ajouter (source retirée qu'on remet) |
| `carteOutil` | Modifier, Allumer/Éteindre |
| le bloc équivalent pour les outils retirés | Ajouter |

Pas touché : le bouton principal d'un panneau ou d'une fenêtre (Enregistrer, Annuler…) — ceux-là
restent en icône + mot, ce ne sont pas des actions de liste.

## 3. Le tooltip au survol — à créer, il n'existe pas

`boutonIcone` porte déjà `aria-label` (lu par un lecteur d'écran), mais **rien ne s'affiche
visuellement au survol** : aucun `title`, aucune infobulle, nulle part dans `/suite` aujourd'hui.

Ajout dans `ui.js` :

````js
export function boutonIcone({ icon, etiquette, onclick, classe = "" }) {
  return h("button", { type: "button", class: `bouton-icone ${classe}`.trim(), "aria-label": etiquette, title: etiquette, onclick }, icone(icon));
}
````

Le `title` HTML natif suffit : infobulle du navigateur, zéro CSS, zéro JS supplémentaire, accessible
par construction. Pas de composant « Infobulle » à créer pour ce point.

Le README du composant **Bouton** (`charte/composants/Bouton/README.md`) gagne une ligne sur cette
règle, et celui de **Pictogrammes** peut mentionner que tout picto d'action porte un `title`.

## Comment momo vérifie

* La ligne source affiche trois boutons icône seule : Modifier, interrupteur, Retirer.
* Éteindre une source allumée depuis la ligne ne redemande rien ; allumer une source qui a un
  avertissement déclaré redemande confirmation (comme aujourd'hui dans le panneau).
* Survoler un bouton d'action de liste affiche son nom en infobulle.
* `test_les_31_pictogrammes_et_le_vocabulaire_ferme` continue de passer : aucun mot nouveau, aucun
  pictogramme nouveau, seul `interrupteur` (déjà existant) est réutilisé sur la ligne source.
* `test_aucune_valeur_de_style_en_dur` continue de passer : aucune nouvelle couleur ou taille, le
  changement est purement structurel (icône au lieu d'icône + mot).
