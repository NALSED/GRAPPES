# 3.8.07 — Attente (quota) → devient « Quand une source est à court »

Répond au point **3.8**, outil 7. Rappel transverse : Modèle (T1), Ce qu'il fait → Description (T2),
Rôle/Effet (spec 1.1), Clé d'API (T4, pas pertinente — aucun service externe).

## Clarifié avec Sednal : « attendre » ne sert à rien ici

Le quota visé est le quota externe d'une source (ex. 100 appels/jour chez elle), pas le budget
d'appels fixé pour la recherche en cours. Un quota qui se renouvelle vite (une limite par minute)
est **déjà géré automatiquement**, sans réglage : `adaptateurs/__init__.py` réessaie déjà une
réponse « attendre » (429/503) jusqu'à 3 fois, en respectant le délai demandé par la source. Un
quota qui se renouvelle lentement (quotidien, mensuel) ne peut pas être attendu dans une recherche —
une attente de quelques minutes n'y changerait rien. **« Attendre » est donc retiré.**

## Ce qui existe déjà, et ce qui manque

Vérifié dans le code : quand une source échoue (y compris pour quota dépassé), la recherche
**continue déjà avec les autres sources** — chaque source est isolée, son échec ne stoppe jamais le
reste. C'est donc déjà le comportement « sauter cette source » par défaut, sans rien à construire.

Ce qui manque : la possibilité d'**arrêter toute la recherche** quand une source précise est à
court de quota — aujourd'hui impossible, une source ne peut jamais stopper les autres.

## Le réglage

« Quand le quota est atteint » devient un choix fermé à deux valeurs :

* **Sauter cette source, continuer les autres** (par défaut — déjà le comportement actuel)
* **Arrêter toute la recherche**

Le champ « Attente maximale » disparaît (plus de sens, voir plus haut).

## Ce que momo change

* `adaptateurs/__init__.py` ou `pont/executer.py` : distinguer une erreur de **quota externe
  dépassé** (429/503 encore présent après les 3 essais, ou un code connu comme 403 avec message de
  quota) des autres erreurs de source — pour que seule cette catégorie déclenche le choix de la
  tuile.
* `pont/executer.py`, boucle d'isolation des sources (`isole()`) : si le réglage de la tuile Attente
  est « Arrêter toute la recherche » et qu'une source échoue pour quota dépassé, déclencher l'arrêt
  propre de la collecte (même mécanisme que la limite d'appels atteinte), au lieu de continuer.
* `suite_graine.py`, `_OUTILS` : mettre à jour la description, le réglage, retirer « Attente
  maximale ». `NON_APPLIQUES["attente"]` disparaît : la tuile devient appliquée.
* `reglages.js`, fiche Attente : un seul menu fermé à deux choix, plus de champ durée.

## Comment momo vérifie

* Une source qui échoue pour une raison quelconque (pas quota) : la recherche continue toujours
  avec les autres, quel que soit le réglage de la tuile — inchangé.
* Une source qui épuise son quota externe, tuile réglée sur « Sauter cette source » : la recherche
  se termine normalement avec les autres sources, comme aujourd'hui.
* La même situation, tuile réglée sur « Arrêter toute la recherche » : la recherche s'arrête
  proprement (ce qui est déjà collecté est gardé, comme pour la limite d'appels).
* Sans tuile Attente posée dans le plan : comportement d'aujourd'hui inchangé (sauter et continuer).
